# AI Echo: Your Smartest Conversational Partner

## Project Overview

AI Echo is a Sentiment Analysis project that analyzes ChatGPT user reviews and classifies them into Positive, Neutral, and Negative sentiments. The project uses Natural Language Processing (NLP) and Machine Learning techniques to understand customer feedback and provide insights into user satisfaction.

---

## Problem Statement

Sentiment analysis is a Natural Language Processing (NLP) technique used to determine the sentiment expressed in a given text. This project aims to analyze ChatGPT user reviews and classify them as Positive, Neutral, or Negative based on the sentiment expressed. The goal is to gain insights into customer satisfaction, identify common concerns, and improve the overall user experience.

## Data Preprocessing

The following preprocessing techniques were applied:

* Handling missing values
* Removing duplicates
* Converting text to lowercase
* Removing special characters
* Tokenization
* Stopword Removal
* Lemmatization
* Sentiment Label Creation

Sentiment Labels:

* Positive → Ratings 4–5
* Neutral → Rating 3
* Negative → Ratings 1–2
